MENIT 0–15 · MULAI DARI CERITA

Siapkan file ceritamu

  1. Buka Notepad atau editor teks yang sudah ada di komputermu.
  2. Buat folder bernama cerita-ajaib. Simpan file baru di dalam folder itu dengan nama index.html.
  3. Jika memakai Notepad, saat menyimpan pilih Save as type: All files agar nama file tidak berubah menjadi index.html.txt.

Untuk cerita pertama ini kita fokus pada beberapa tag yang langsung berguna. Bagian tambahan yang belum dibutuhkan bisa dipelajari nanti.

MENIT 15–30 · JUDUL DAN AWAL CERITA

Kenali beberapa tag saja

Salin contoh ini ke index.html. Kita gunakan kerangka sederhana, lalu isi ceritanya di dalamnya.

<html>
  <head>
    <title>Nara dan Naga Kecil</title>
  </head>
  <body>
    <h1>Nara dan Naga Kecil</h1>
    <p>Sore itu, Nara mendengar suara kecil dari balik semak.</p>
    <p>Seekor naga mungil muncul. Sayapnya berkilau seperti pelangi!</p>
  </body>
</html>
<html>...</html>
Pembungkus halaman web. Semua bagian halaman berada di dalamnya.
<head>...</head>
Tempat informasi halaman yang tidak menjadi isi cerita. Untuk sekarang, bagian ini hanya berisi judul tab.
<title>...</title>
Nama halaman yang muncul di tab browser. Ganti dengan judul ceritamu.
<body>...</body>
Tempat isi yang terlihat di halaman, seperti judul cerita dan paragraf.
<h1>...</h1>
Judul utama cerita. Biasanya tampil paling besar.
<p>...</p>
Satu paragraf, seperti satu atau beberapa kalimat dalam cerita.
Tag pembuka dan penutup
<p> membuka paragraf, lalu </p> menutupnya. Teks ceritamu ditulis di antara keduanya. Tag <html>, <head>, dan <body> juga punya pasangan seperti ini.

Coba sekarang: simpan file, lalu buka index.html dengan browser. Kamu seharusnya melihat judul dan dua paragraf cerita.

MENIT 30–40 · LANJUTKAN PETUALANGAN

Apa yang terjadi berikutnya?

Tambahkan dua baris ini di dalam <body>, tepat sebelum </body>. Tag h2 membuat judul bagian yang lebih kecil daripada h1; tag p membuat paragraf baru.

<h2>Teman baru</h2>
<p>Nara menawarkan bantuan. Naga itu tersenyum dan menunjukkan peta rahasia.</p>

Ubah kalimatnya supaya cocok dengan imajinasimu. Simpan file dan segarkan browser untuk membaca lanjutannya.

Ide cerita: ke mana peta itu membawa Nara? Apa nama naga kecilnya? Kamu yang menentukan jawabannya.

MENIT 40–55 · HIAS DENGAN WARNA

Beri suasana pada ceritamu

Sekarang buat file kedua bernama style.css di folder yang sama. Agar halaman mengenal file gaya ini, tambahkan satu baris berikut di dalam <head>, tepat sebelum </head>:

<link rel="stylesheet" href="style.css">

Baris itu menghubungkan ceritamu dengan file bernama style.css. Sekarang salin dua aturan sederhana ini ke dalam file CSS:

body {
  background-color: lightyellow;
  font-family: Arial, sans-serif;
}

h1 {
  color: tomato;
}
  • body memilih halaman; h1 memilih judul utama.
  • Di dalam kurung kurawal { }, tulis gaya yang ingin diubah.
  • background-color mengubah warna halaman; color mengubah warna tulisan.

Simpan kedua file dan segarkan browser. Coba ganti lightyellow dengan lightblue, lalu lihat perubahan suasana cerita.

MENIT 55–60 · PILIH AKHIR CERITAMU

Petualangannya belum selesai!

Pilih satu hal untuk diubah atau ditambahkan. Satu perubahan kecil pun sudah hebat.

  • Ganti nama tokoh atau naga kecilnya.
  • Tulis akhir cerita dengan satu paragraf baru menggunakan <p>...</p>.
  • Ubah warna judul dari tomato menjadi royalblue atau warna lain.

Kalau hasilnya belum berubah: pastikan kedua file berada di folder yang sama, namanya tepat, dan perubahan sudah disimpan sebelum browser disegarkan.

Kamu sudah membuat halaman cerita!

Hari ini kamu memakai judul dan paragraf untuk bercerita, lalu mengubah warna halaman dengan CSS. Kamu tidak perlu menghafal apa pun—di kelas kita akan berlatih lagi dengan proyek yang menyenangkan, satu langkah setiap kali.

Kalau ceritamu punya judul sendiri, naga yang unik, dan akhir pilihanmu, berarti halaman itu sudah menjadi milikmu.
